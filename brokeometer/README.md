# BrokeOMeter

Βγαίνεις τον μήνα ή όχι; Γράψε τι μπαίνει και τι βγαίνει, και ο μετρητής σου λέει την αλήθεια.

**Άνοιξέ το:** https://ferelisvag.github.io/published/brokeometer/

- Έσοδα και έξοδα ανά κατηγορία, το καθένα στη συχνότητα που το πληρώνεις (μήνα, ×14, ημέρα, εβδομάδα, τρίμηνο, χρόνο, 2 χρόνια)
- Μετρητής με ετυμηγορία και σενάριο «μόνο σίγουρα έσοδα»
- Κατανομή εξόδων, προειδοποιήσεις και στόχος αποταμίευσης
- Εξαγωγή σε Excel (με τύπους) και PDF
- Τα στοιχεία μένουν μόνο στον browser σου

## Αρχεία

| Αρχείο | Τι είναι |
|---|---|
| `index.html` | Όλη η εφαρμογή (inline CSS/JS) |
| `favicon.svg`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` | Εικονίδια |
| `manifest.webmanifest` | Για «Προσθήκη στην αρχική οθόνη» στο κινητό |
| `logo.svg` | Λογότυπο με το όνομα |
