# Πού έχω πάει

Δες σε χάρτη πού έχεις πάει, από το Χρονολόγιο (Timeline) των Χαρτών Google. Φορτώνεις το αρχείο `Timeline.json` του κινητού σου και βλέπεις μέρη, διαδρομές, χώρες και ταξίδια.

**Άνοιξέ το:** https://ferelisvag.github.io/published/pou-exo-pai/

- Η ίδια η σελίδα έχει οδηγίες για εντελώς αρχάριους: πώς βγάζεις το αρχείο από Android και iPhone, πώς το φέρνεις στον υπολογιστή, τι σημαίνουν τα σφάλματα.
- Το αρχείο διαβάζεται και επεξεργάζεται **μόνο στον browser σου**. Δεν ανεβαίνει πουθενά, η σελίδα δεν κάνει καμία δικτυακή κλήση και δουλεύει και χωρίς internet.
- Τίποτα δεν αποθηκεύεται αν δεν το ζητήσεις: το τσεκάρισμα «Να θυμάται τα αποτελέσματα» είναι προαιρετικό και εξηγείται πριν. Κουμπί «Διαγραφή δεδομένων» τα σβήνει.
- Δέχεται και τις δύο μορφές του `Timeline.json` (Android και iPhone/iPad).

## Αρχεία

| Αρχείο | Τι είναι |
|---|---|
| `index.html` | Όλη η εφαρμογή και οι οδηγίες (inline CSS/JS, ~3 MB με τη βάση πόλεων). Βγαίνει από το `source/` |
| `favicon.svg`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` | Εικονίδια |
| `manifest.webmanifest` | Για «Προσθήκη στην αρχική οθόνη» |
| `source/` | Ό,τι χρειάζεται για να ξαναχτιστεί η `index.html` |

## Πώς ξαναχτίζεται

```
cd source
python3 build.py "Έκδοση 7.11 · 23:52"
```

- `build.py`: συναρμολογεί την `../index.html` (οδηγίες, κέλυφος, αποθήκευση, footer).
- `dashboard.html`: οι οθόνες του dashboard (Επισκόπηση, Χάρτης, Περιοχές, Ταξίδια).
- `proc.js`: η επεξεργασία (επισκέψεις, διαδρομές, έδρα, ταξίδια). Τρέχει σε Web Worker.
- `cities.json.gz`: GeoNames cities1000 (CC BY 4.0), για τα ονόματα τοποθεσιών.
- `d3.min.js`, `outline.json`: βιβλιοθήκη και περίγραμμα χάρτη.
