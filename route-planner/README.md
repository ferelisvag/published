# Δρομολόγια Ιωαννίνων

Web εφαρμογή για κινητό και υπολογιστή που βρίσκει τη βέλτιστη σειρά για έως 30 στάσεις, με αφετηρία και επιστροφή στο ίδιο σημείο (προεπιλογή: Ιωάννινα).

https://ferelisvag.github.io/published/route-planner/

## Τι κάνει

- Στάσεις με πάτημα στον χάρτη, με αναζήτηση διεύθυνσης ή από τους αποθηκευμένους πελάτες (έως 30). Οι πινέζες σέρνονται για διόρθωση.
- Δύο κριτήρια διαδρομής:
  - **Γρηγορότερη**: λιγότερος χρόνος, με εθνικές οδούς και διόδια.
  - **Λιγότερα km**: συντομότερη σε απόσταση, από τοπικούς δρόμους, χωρίς εθνικές και διόδια.
- Βέλτιστη σειρά στάσεων, διαδρομή στον χάρτη, συνολικά km και χρόνος, km και χρόνος ανά σκέλος.
- Κοινή χρήση: link που ανοίγει την ίδια διαδρομή σε άλλη συσκευή.
- Αποθήκευση σε αρχείο: GPX (για εφαρμογές πλοήγησης, ξαναφορτώνεται στην εφαρμογή) και CSV (ανοίγει στο Excel).
- Πλοήγηση στο Google Maps, χωρισμένη σε κομμάτια των έως 8 ενδιάμεσων στάσεων.
- Αποθηκευμένοι πελάτες (☆), με προσθήκη όλων με ένα κουμπί.
- Τα δεδομένα μένουν στη συσκευή (στον browser). Δεν υπάρχει δικός μας server ή βάση.

## Πώς δουλεύει

Η βέλτιστη σειρά υπολογίζεται μέσα στην εφαρμογή, από πίνακα αποστάσεων ή χρόνων ανάμεσα σε όλες τις στάσεις.

| | Γρηγορότερη | Λιγότερα km |
|---|---|---|
| Πίνακας και χάραξη | OSRM (routing.openstreetmap.de, εφεδρεία router.project-osrm.org) | Valhalla (valhalla1.openstreetmap.de) |
| Εφεδρεία | δεύτερος server OSRM | OSRM με βάση τα km |

Αναζήτηση διευθύνσεων: Photon. Χάρτης: OpenStreetMap. Όλα δωρεάν, χωρίς εγγραφή.

Προαιρετικά, με δωρεάν κλειδί από το openrouteservice.org (Ρυθμίσεις μέσα στην εφαρμογή) εμφανίζεται η επιλογή για φορτηγό.

## Περιορισμοί

- Οι δωρεάν servers δεν έχουν εγγύηση διαθεσιμότητας. Για λίγες διαδρομές τη μέρα είναι αρκετοί.
- Οι χρόνοι δεν περιλαμβάνουν κίνηση. Για ζωντανή κίνηση η πλοήγηση γίνεται στο Google Maps.
- Το Google Maps χαράζει μόνο του τον δρόμο ανάμεσα στις στάσεις. Για "Λιγότερα km" ενεργοποίησε εκεί την αποφυγή αυτοκινητοδρόμων και διοδίων.
