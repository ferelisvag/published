# Δρομολόγια Ιωαννίνων

Web εφαρμογή για κινητό και υπολογιστή που βρίσκει τη βέλτιστη σειρά για έως 30 στάσεις, με αφετηρία και επιστροφή στο ίδιο σημείο (προεπιλογή: Ιωάννινα).

## Τι κάνει

- Στάσεις με πάτημα στον χάρτη ή με αναζήτηση διεύθυνσης (έως 30). Οι πινέζες σέρνονται για διόρθωση.
- Αλλαγή αφετηρίας/επιστροφής.
- Επιλογή οχήματος (αυτοκίνητο/βαν ή φορτηγό) και "Χωρίς διόδια".
- Βέλτιστη σειρά στάσεων, διαδρομή στον χάρτη, συνολικά km και χρόνος, km και χρόνος ανά σκέλος.
- Πλοήγηση στο Google Maps, χωρισμένη σε κομμάτια των έως 8 ενδιάμεσων στάσεων.
- Αποθηκευμένοι πελάτες (☆) για γρήγορη προσθήκη.
- Τα δεδομένα μένουν στη συσκευή (στον browser). Δεν υπάρχει server ή βάση.

## Κόστος

Μηδενικό, χωρίς εγγραφή. Χάρτης από OpenStreetMap, δρομολόγηση από τον δημόσιο server του OSRM, αναζήτηση διευθύνσεων από το Photon.

Προαιρετικά, με δωρεάν κλειδί από το openrouteservice.org (Ρυθμίσεις μέσα στην εφαρμογή) ενεργοποιείται η δρομολόγηση για φορτηγό και πιο αξιόπιστη υπηρεσία. Ο δημόσιος server του OSRM δεν έχει εγγύηση διαθεσιμότητας. Για λίγες διαδρομές τη μέρα είναι αρκετός.

## Στήσιμο

### 1. Δημοσίευση
Η εφαρμογή δημοσιεύεται με GitHub Pages από το repo `ferelisvag/published` (branch `main`):

https://ferelisvag.github.io/published/route-planner/

Κάθε νέο push στο `main` ανεβαίνει αυτόματα σε 1–2 λεπτά.

### 2. Στο κινητό του οδηγού
Άνοιξε το link στον browser → Μενού → "Προσθήκη στην αρχική οθόνη". Εμφανίζεται σαν εφαρμογή. Δεν χρειάζεται κλειδί.

## Περιορισμοί

- Χωρίς κλειδί η επιλογή φορτηγού δεν εμφανίζεται, και το "Χωρίς διόδια" μπορεί να ισχύει μόνο στην πλοήγηση Google Maps.
- Με κλειδί, το "Χωρίς διόδια" επηρεάζει τη διαδρομή στον χάρτη και στο Google Maps. Η σειρά των στάσεων υπολογίζεται με τον συνηθισμένο οδικό χάρτη.
- Οι χρόνοι δεν περιλαμβάνουν κίνηση. Για ζωντανή κίνηση η πλοήγηση γίνεται στο Google Maps.
