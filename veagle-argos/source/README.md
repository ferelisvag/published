# Veagle Argos · Panoptis

Ο Άργος ο Πανόπτης, ο φύλακας με τα εκατό μάτια. Φορητό πρόγραμμα προβολής για τις κάμερες του σπιτιού (ONVIF / RTSP), μόνο για τοπική χρήση.
Από το VEAGLE - [ferelis.gr](https://ferelis.gr). Ένα `.exe`, χωρίς εγκατάσταση και χωρίς έξτρα κατεβάσματα. Τρέχει και από στικάκι.

## Χρήση

1. Αντέγραψε το `dist\VeagleArgos.exe` όπου θέλεις (π.χ. στικάκι) και άνοιξέ το.
2. **⚙ Κάμερες → 🔍 Αναζήτηση στο δίκτυο**, διάλεξε κάμερα → **Προσθήκη**.
3. Γράψε χρήστη και κωδικό, πάτα **⟳ Ανάκτηση ροών μέσω ONVIF**, μετά **Αποθήκευση**.
   - Εναλλακτικά γράψε απευθείας τη διεύθυνση RTSP.

Δίπλα στο `.exe` δημιουργούνται:
- `argos_config.json`: οι κάμερες και οι ρυθμίσεις (**οι κωδικοί είναι μέσα σε απλό κείμενο**, πρόσεχε σε ποιον δίνεις το στικάκι)
- `snapshots\`: τα στιγμιότυπα
- `recordings\`: οι εγγραφές (`.mp4`, νέο αρχείο κάθε ώρα)

## Χειρισμός

| Ενέργεια | Τι κάνει |
|---|---|
| `1` / `2` / `4` | Διάταξη 1×1 / 1×2 / 2×2 |
| `←` `→` | Προηγούμενη / επόμενη σελίδα (ή κάμερα στο 1×1) |
| Κλικ σε κάμερα | Επιλογή και **ήχος** από αυτή. Ξανά κλικ: αποεπιλογή, ο ήχος σταματά |
| Διπλό κλικ σε κάμερα | Μεγέθυνση σε 1×1 και πίσω |
| Ροδέλα | Ψηφιακό ζουμ (έως 8×) εκεί που δείχνει το ποντίκι |
| Σύρσιμο με ζουμ | Μετακίνηση της εικόνας |
| Σύρσιμο χωρίς ζουμ | Αλλαγή σειράς: ρίξε την κάμερα πάνω σε άλλη |
| Δεξί κλικ | Επαναφορά ζουμ |
| `AUTO` / `HD` / `SD` πάνω δεξιά | Ποιότητα ροής ανά κάμερα (AUTO = SD στο πλέγμα, HD στο 1×1) |
| Βελάκια μέσα στο πλαίσιο | Περιστροφή κάμερας PTZ (εμφανίζονται με το ποντίκι από πάνω, μόνο σε κάμερες που γυρίζουν) |
| `S` | Στιγμιότυπο (σε πλήρη ανάλυση, αν είναι ανοιχτή η HD ροή) |
| `R` | Εγγραφή της επιλεγμένης κάμερας σε HD (ξανά `R`: τέλος) |
| `M` / slider | Σίγαση / ένταση ήχου |
| `C` | Αυτόματη εναλλαγή σελίδων/καμερών (ο χρόνος ρυθμίζεται στις «Κάμερες») |
| `F11` / `F` / `Esc` | Πλήρης οθόνη / έξοδος |

Τα πλήκτρα δουλεύουν και με ελληνικό πληκτρολόγιο.

Στις «Κάμερες» υπάρχουν επίσης επιλογές για ώρα και ημερομηνία πάνω στην εικόνα και για άνοιγμα
κατευθείαν σε πλήρη οθόνη.

Οι εγγραφές κρατούν την εικόνα όπως έρχεται από την κάμερα (ελάχιστη CPU) και τον ήχο σε AAC.
Αν χαθεί για λίγο το σήμα, η εγγραφή συνεχίζει στο ίδιο αρχείο.

## Κάμερες TP-Link Tapo (C210, C320WS, C520WS κ.λπ.)

- Στην εφαρμογή Tapo: **Κάμερα → Ρυθμίσεις → Σύνθετες ρυθμίσεις → Λογαριασμός κάμερας**, φτιάξε χρήστη και κωδικό.
  Αυτά μπαίνουν στο πρόγραμμα (όχι ο λογαριασμός TP-Link cloud).
- Το ONVIF των Tapo είναι στη θύρα **2020**. Η αναζήτηση τη βρίσκει μόνη της.
- Χειροκίνητα: `rtsp://192.168.x.x:554/stream1` (HD) και `.../stream2` (SD).

## Αν δεν βρίσκει κάμερα

- Ίδιο δίκτυο / Wi-Fi με τις κάμερες.
- Την πρώτη φορά τα Windows μπορεί να ρωτήσουν για το Firewall: επίτρεψε το **Ιδιωτικό δίκτυο**.
- Η αναζήτηση ρωτάει όλο το τοπικό δίκτυο (/24). Αν πάλι δεν τη βρει, πρόσθεσέ την χειροκίνητα με την IP.

## Build (για προγραμματιστή)

Χρειάζεται Python 3 μόνο στον υπολογιστή που φτιάχνει το `.exe`.

```
powershell -ExecutionPolicy Bypass -File build.ps1
```

Βγάζει το `dist\VeagleArgos.exe` (~60 MB, περιέχει Python, PyAV/FFmpeg και PortAudio).

Αρχεία:
- `veagle_homecam.py`: η εφαρμογή (tkinter + PyAV για εικόνα, ήχο και εγγραφή · sounddevice για τα ηχεία)
- `onvif_lite.py`: ONVIF discovery, GetProfiles και GetStreamUri, χωρίς εξωτερικές βιβλιοθήκες
