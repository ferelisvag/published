# Investment Calculator (Υπολογιστής Επένδυσης)

Μια απλή, γρήγορη και διαδραστική web εφαρμογή υπολογισμού σύνθετου τόκου (compound interest) με αρχικό κεφάλαιο, μηνιαίες καταθέσεις και γραφική απεικόνιση.

## Χαρακτηριστικά
- Υπολογισμός τελικής αξίας, συνολικών καταθέσεων και κέρδους από τόκους.
- Δυναμικό γράφημα εξέλιξης επένδυσης με τη βοήθεια της Chart.js.
- Σύγχρονος και καθαρός σχεδιασμός με Tailwind CSS.

## Οδηγίες Χρήσης
1. Αποσυμπίεσε το αρχείο zip.
2. Ανέβασε το αρχείο `index.html` στο GitHub repository σου (ή άνοιξε το τοπικά σε οποιονδήποτε browser).
