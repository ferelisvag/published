# Υπολογιστής Επένδυσης

Πόσο μεγαλώνουν τα χρήματά σου αν βάζεις κάτι κάθε μήνα και αφήνεις τον ανατοκισμό να δουλέψει;

**Άνοιξέ το:** https://ferelisvag.github.io/published/veaglefinancecalc/

- Αρχικό ποσό, μηνιαία κατάθεση, ετήσια απόδοση και διάρκεια σε έτη
- Τελική αξία, σύνολο καταθέσεων και κέρδος από τόκους
- Γράφημα ανά έτος: συνολική αξία μαζί με όσα κατέθεσες
- Ανατοκισμός κάθε μήνα (ετήσια απόδοση ÷ 12), με την κατάθεση στην αρχή του μήνα
- Ποσά σε ελληνική μορφή, τίποτα δεν αποθηκεύεται ούτε στέλνεται πουθενά

Ενημερωτικό εργαλείο: τα αποτελέσματα υποθέτουν σταθερή απόδοση και δεν είναι επενδυτική συμβουλή.

## Αρχεία

| Αρχείο | Τι είναι |
|---|---|
| `index.html` | Όλη η εφαρμογή (inline CSS/JS, το γράφημα με Chart.js 4.4.1 από cdnjs) |
| `favicon.svg`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` | Εικονίδια |
| `manifest.webmanifest` | Για «Προσθήκη στην αρχική οθόνη» στο κινητό |
| `logo.svg` | Λογότυπο με το όνομα |
