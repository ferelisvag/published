# Veagle on the road

Διαδρομές με μηχανή: σχεδίαση με τη σειρά που θες, πολυήμερα ταξίδια, και δημόσιες διαδρομές που βλέπουν όλοι.

https://ferelisvag.github.io/published/veagleontheroad/

## Τι κάνει

- Σημεία με πάτημα στον χάρτη ή αναζήτηση, με τη σειρά που ορίζεις (↑ ↓), έως 60. Το πρώτο είναι η αφετηρία, το τελευταίο ο προορισμός.
- Τύποι σημείων με εικονίδιο και ονομασία όταν περνάς από πάνω: 🏠 αφετηρία, 🤝 σημείο συνάντησης, ☕ καφές, 📷 φωτογραφία, 🍽️ φαγητό, ⛽ βενζίνη, 🏞️ αξιοθέατο/θέα, 📍 στάση, 🌙 διανυκτέρευση, 🏁 προορισμός.
- **Σημείο συνάντησης**: χωρίζει τη διαδρομή σε προσωπικό κομμάτι (από το σπίτι του καθενός) και **κοινή διαδρομή** της παρέας. Τα km μετράνε για τον καθένα από τη δική του αφετηρία. Η κοινή χρήση και το GPX μοιράζονται την κοινή διαδρομή. Όποιος την ανοίγει προσθέτει τη δική του αφετηρία.
- Ώρα αναχώρησης και χρόνος στάσης ανά σημείο, με ώρα άφιξης σε κάθε σημείο, στη συνάντηση, στον προορισμό και πίσω στο σπίτι. Μετά από διανυκτέρευση η επόμενη μέρα ξεκινάει την ίδια ώρα.
- Στυλ διαδρομής: **Στροφές & επαρχία** ή **Άμεση με διόδια**. Αποφυγή διοδίων, χωματόδρομων, πορθμείων. Επιστροφή στην αφετηρία.
- Κατάσταση: Προσχέδιο ή Δοκιμασμένη. Ορατότητα: Ιδιωτική ή Δημόσια.
- Καρτέλα «Διαδρομές» με όλες τις δημόσιες, για όλους, χωρίς είσοδο (φίλτρο «Μόνο δοκιμασμένες»).
- Καρτέλα «Οι διαδρομές μου» για όσους έχουν κωδικό.
- GPX, link κοινής χρήσης, πλοήγηση στο Google Maps χωρισμένη σε «προς τη συνάντηση», «κοινή διαδρομή» και «επιστροφή».

## Πρόσβαση και ρόλοι

Η είσοδος γίνεται με **όνομα + κωδικό**. Ο κωδικός είναι ένα fine-grained token του GitHub που φτιάχνει ο διαχειριστής και το δίνει στον φίλο. Οι διαδρομές και η ομάδα αποθηκεύονται στο private repo `ferelisvag/veagleontheroad-data`. Οι δημόσιες αντιγράφονται στον φάκελο `routes/` εδώ.

| Ρόλος | Τι κάνει |
|---|---|
| Χωρίς είσοδο | Βλέπει τις δημόσιες, σχεδιάζει μόνο στη συσκευή του |
| Μέλος | Αποθηκεύει δικές του διαδρομές, βλέπει όσες της παρέας του, κάνει προτάσεις σε εκδρομές που συμμετέχει, αντιγράφει την κοινή διαδρομή στο προφίλ του |
| Αρχηγός εκδρομής | Αλλάζει την κοινή διαδρομή της εκδρομής, εγκρίνει ή απορρίπτει προτάσεις |
| Δικαίωμα «Δημοσίευση» | Κάνει διαδρομές δημόσιες (χρειάζεται κωδικό με πρόσβαση και στο `published`) |
| Δικαίωμα «Δοκιμασμένη» | Σημειώνει διαδρομές ως δοκιμασμένες |
| Διαχειριστής | Όλα τα παραπάνω, και η καρτέλα «Διαχείριση»: χρήστες, δικαιώματα, παρέες |

Τα δικαιώματα της «Διαχείρισης» τα σέβεται η εφαρμογή. Το τι μπορεί πραγματικά να γράψει ένας κωδικός το ορίζει το GitHub: ο κωδικός μέλους έχει πρόσβαση μόνο στο `veagleontheroad-data`.

## Στήσιμο (μία φορά)

1. **Private repo**: github.com/new → `veagleontheroad-data` → Private → Create.
2. **Ο δικός σου κωδικός**: GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token.
   - Repository access: Only select repositories → `published` και `veagleontheroad-data`
   - Permissions → Repository permissions → **Contents: Read and write**
   - Generate → αντέγραψε τον κωδικό → στην εφαρμογή «Είσοδος» με το όνομά σου.
3. Την πρώτη φορά γίνεσαι αυτόματα διαχειριστής. Πήγαινε στη **Διαχείριση** και πρόσθεσε χρήστες και παρέες.

## Κωδικός για φίλο

1. Ίδια βήματα με το 2, με όνομα π.χ. «Veagle – Νίκος» και Repository access **μόνο** `veagleontheroad-data` (πρόσθεσε και `published` αν θα δημοσιεύει).
2. Στείλε του τον κωδικό.
3. Στη **Διαχείριση** πρόσθεσέ τον με το **ίδιο όνομα** που θα γράφει στην Είσοδο, τσέκαρε δικαιώματα, βάλ' τον σε παρέα, Αποθήκευση.
4. Ακύρωση: Delete στο token στο GitHub, και αφαίρεση από τη Διαχείριση.

## Εκδρομή παρέας

1. Σχεδίασε τη διαδρομή με 🤝 **σημείο συνάντησης**.
2. Τσέκαρε **Εκδρομή παρέας**, διάλεξε **αρχηγό** και ποιοι **συμμετέχουν**, Αποθήκευση.
3. Τα μέλη τη βλέπουν στις «Οι διαδρομές μου». Μπορούν να:
   - αλλάξουν σημεία και να στείλουν **Πρόταση αλλαγής** με σημείωση,
   - πατήσουν **Αντιγραφή στο προφίλ μου**, να βάλουν τη δική τους αφετηρία και να αποθηκεύσουν. Το αντίγραφο έχει 🔒 στην κοινή διαδρομή και **ενημερώνεται αυτόματα** όταν ο αρχηγός την αλλάξει.
4. Ο αρχηγός βλέπει τις **Προτάσεις αλλαγών** με το όνομα του φίλου και τι αλλάζει (+ νέο, − αφαιρείται, ≈ αλλαγή τύπου), πατάει Προβολή, Αποδοχή ή Απόρριψη. Μετά από αποδοχή: Υπολόγισε → Αποθήκευση αλλαγών.
