Συμμετέχουν

Ο αρχηγός αλλάζει την κοινή πορεία. Τα μέλη τη βλέπουν, κάνουν προτάσεις και την αντιγράφουν στο προφίλ τους με τη δική τους αφετηρία.

Στυλ διαδρομής

Αποφυγή

Χρόνοι

Σε κάθε στάση ορίζεις πόσα λεπτά θα μείνετε (π.χ. καφές 30'). Βγαίνει η ώρα άφιξης σε κάθε σημείο και στον προορισμό. Μετά από διανυκτέρευση η επόμενη μέρα ξεκινάει την ίδια ώρα.

Αναζήτηση σημείου

Σημεία

    Πάτα στον χάρτη για να βάλεις σημεία με τη σειρά που θες να περάσεις. Το πρώτο είναι η αφετηρία σου, το τελευταίο ο προορισμός. Στα ενδιάμεσα διαλέγεις τύπο: σημείο συνάντησης, καφές, φωτογραφία, φαγητό, βενζίνη, θέα, στάση ή διανυκτέρευση.

    Πάτα στον χάρτη ή ψάξε σημείο για την αφετηρία σου.

    Προτάσεις αλλαγών

    Πρόταση αλλαγής

    Η διαδρομή είναι του αρχηγού. Άλλαξε σημεία στον χάρτη και στη λίστα, γράψε τι προτείνεις και στείλ' το. Δεν αλλάζει το πρωτότυπο μέχρι να το εγκρίνει.

    Αποθηκευμένες

    Χρήστες

    ΌνομαΔιαχ.Δημοσ.Δοκιμ.

    Το όνομα πρέπει να είναι ίδιο με αυτό που γράφει ο φίλος στην Είσοδο. Η «Δημοσίευση» δουλεύει μόνο αν ο κωδικός του έχει πρόσβαση και στο repo published.

    Παρέες

    Κάθε μέλος βλέπει τις διαδρομές των μελών της παρέας του. Αν δεν υπάρχει καμία παρέα, όλοι βλέπουν όλες.

    Πώς δίνω κωδικό σε φίλο
    1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
    2. Όνομα π.χ. «Veagle – Νίκος», λήξη π.χ. 1 χρόνος.
    3. Repository access → Only select → veagleontheroad-data (και published αν θα δημοσιεύει).
    4. Permissions → Repository → Contents: Read and write → Generate.
    5. Στείλε του τον κωδικό και πρόσθεσέ τον εδώ με το ίδιο όνομα που θα γράφει στην Είσοδο.
    6. Για ακύρωση: Delete στο token από την ίδια σελίδα.
